# Fitbook self-hosted fonts

Lora (headings) and DM Sans (body/UI), normal variable weights 400–700.
Latin and Latin-ext subsets include the Turkish glyphs used by the site.
Downloaded from the official Google Fonts CSS API on 2026-09-28.
Each font is distributed with its unmodified OFL license in this directory.

Official family metadata:
- https://raw.githubusercontent.com/google/fonts/main/ofl/lora/METADATA.pb
- https://raw.githubusercontent.com/google/fonts/main/ofl/dmsans/METADATA.pb
